# 我的工作台

访问：https://solen-w.github.io/personal-workbench/

固定授权账号入口为前端校验，不能替代服务端认证；私有内容通过用户的 GitHub 令牌授权访问。原始账号 TXT 不进入本仓库。

## 内容页

- 个人系统：基础情况（可导出 CSV）、学工经历（可导出 CSV）、财务管理。
- 生活系统：身体跟踪、习惯养成、图书管理。
- 目标系统：运动挑战、专项攻克、理论学习。
- 文件系统：工作要求、政策法规、素材收集（文字、图片、文件）。

财务管理依次包含账户管理、投资观察、预算实用、总览统计、事项储蓄，默认打开账户管理；固定预算、结余回收与克制分析合并在预算实用页面。预算以周一至周日为一周；固定预算持续生效，后续可从另一周调整。

可用结余 = 周固定预算 − 实际支出 − 手动回收金额。支出率 = 实际支出 ÷ 周固定预算，以百分比显示，不设主观克制等级；没有预算时不计算支出率。回收须手动记录，不能超过当周可回收结余。可选账户转存仅是账簿记录，转存不重复计作支出。账户余额按期初余额和关联记录计算。

投资观察支持手工及后台行情更新、持仓估值和交易记账；事项储蓄的已存金额独立手动维护。身体跟踪记录体重、身高、腰围、睡眠与运动，不自动作健康判断。

分组和条目保持用户指定顺序。顶部圆形头像与名称可编辑，保存在本地并通过私有仓库随内容同步；已有浏览器外观设置自动迁移；底部保留同步与设置。手机采用抽屉侧栏，平板和电脑使用固定侧栏。

## 数据

内容保存在浏览器 IndexedDB。手动同步的数据文件仍为私有仓库 `data/tasks.json`，格式升级为 schemaVersion 8，包含旧 tasks、删除标记、新 records 及对应删除标记。

旧版模块按名称映射到新分类，文字与图片合并至素材收集的对应子页，保留内容、附件和删除标记。旧任务不会删除，在对应条目的“原有任务”入口可导出。旧版客户端不识别 schemaVersion 8，会拒绝覆盖新版数据；各设备应使用此网址的新版页面。

附件保存在 IndexedDB 和私有仓库 `data/assets/<id>`，不会上传公开网页仓库。单个附件上限 8 MB；主数据 JSON 上限 8 MB。同步先上传附件，再提交引用记录。勾选“在此设备记住令牌”后，GitHub 同步令牌保存在此浏览器的独立 IndexedDB 凭据条目中，按数据仓库区分；刷新和重新登录会自动恢复。取消勾选则只在当前会话使用。“清除令牌”删除此设备对应仓库的保存值并清除当前会话值。令牌不进入内容状态、同步、JSON 备份或源码。

附件按需下载到设备本地，只有已缓存的文件可以离线打开。删除条目会同步删除标记，附件保留以避免破坏其他版本或备份。

导出完整 JSON 备份包含内容和附件，附件未缓存时需要令牌联网下载。附件总量最多 44 MB，导入文件最大 64 MB；更大资料应保留 GitHub 私有仓库副本并分别下载附件。

## 微信读书

图书管理展示微信读书阅读看板，原有手动书目数据保留在数据与备份中，不再显示旧卡片。看板展示累计与年度阅读/收听时长、每日热力表、按封面展示的电子书和有声书；支持搜索和状态筛选。书架里未读的书不会默认当作已读书籍。接口未返回的日期显示为未知，不填零。

官方 Skill 1.0.6 使用 `https://i.weread.qq.com/api/agent/gateway`。跨域检测仅允许微信读书源站，因此公开静态网页不收集或直传微信读书密钥。私有数据仓库中的手动 GitHub Actions 工作流读取 Secret `WEREAD_API_KEY`，将净化后的阅读快照写入 `data/weread.json`；网页用已有 GitHub Contents 令牌读取该文件并缓存到当前设备。密钥不写入快照、源码、日志或本地页面。该工作流没有定时任务，网页提交更新请求时自动运行。

首次使用：在图书管理的“连接配置”中打开私有仓库 Secrets，新建 `WEREAD_API_KEY`。之后只需在图书管理点击“更新阅读”，无需打开 GitHub 运行工作流。历史年份可在运行工作流时填入 year，多次运行会保留已获取年份。年度明细缺失时，同步程序按自然月读取每日明细；累计时长始终使用 overall 的 totalReadTime，年度时长使用对应年的 totalReadTime，单位均为秒。网页缓存快照后可离线查看数据；外部封面是否可离线显示取决于浏览器图片缓存。

官方文档：https://github.com/Tencent/WeChatReading/tree/main/skills

## 投资观察与交易记账

投资观察为同页分类表格，按股票、基金、贵金属展示四组双行字段；顶部显示投资总市值、持仓收益额和收益率，没有三类分页选择器。页面不显示来源标注。旧债券等观察记录保留在“其他”分类，既有份额与成本不被覆盖。

新增持仓可关联账户管理中的投资类资金账户。初始股票和基金成本从该账户可用资金中扣除，同时持仓市值计入该账户；贵金属初始登记不扣现金，按克重计值。未关联的旧观察记录保留为观察数据，交易前需关联投资类资金账户。账户总金额=可用资金+持仓估值+申购待确认金额+赎回待到账金额，避免现金及市值重复计入；转出仅限可用资金。

股票及贵金属买卖使用用户填写的实际成交数量、价格、总费用和日期。买入总支付计入成本，卖出按移动加权平均结转成本；记录已实现收益，不提供证券交易下单。资金不足、超卖、已有交易后重写初始份额/成本和回插成交日期均拒绝。

基金申购先预留金额，实际确认后才增加份额；确认金额与份额、净值、费用核对，不重复扣款。赎回先冻结份额，实际确认后减少持仓并形成应收，实际到账后才增加可用资金；待确认可撤销或登记失败。预计T+1/T+2按15时分界、周末和已核实2026休市日计算，境外或其他年度只作预计。实际确认净值不会用行情自动代填。重复确认及到账不重复记账，同步冲突结果不同需在详情中显式核对选择。

行情在私有仓库后台按公开代码查询，网页一键读取结果，正常进入页面时按15分钟间隔检查。请求不包含数量、成本、账户或个人信息。贵金属自动报价当前仅为GOLD积存金参考克价；其他品种可手工维护价格。报价失败保留旧值，旧报价不覆盖更新的报价；缺价不冒充全损，总市值显示已报价部分并提示待报价。报价时间保留在详情中。

本次验证：104 项 JS 测试、10 项 Python 测试，DOM/IndexedDB 模拟覆盖分类表格、买卖、基金申请确认到账撤销、资金不足、初始化编辑保护、后台刷新、无来源标注和既有同步/令牌流程。没有在用户账户中保存测试交易，尚未完成鸿蒙设备上的这些交易表单验证。

### 分类投资账户

投资观察中的“账户设置”可分别启用股票、基金、贵金属资金账户；启用时填写登记持仓之前的初始资金，三类持仓均扣除初始化成本，交易与基金结算自动更新可用余额。未启用时不保存初始金额，允许直接添加持仓及登记交易，不限制虚拟资金余额。账户管理的投资分类固定生成股票、基金、贵金属三个条目，启用显示可用资金、持仓和在途资金合计，未启用仅显示已报价持仓市值。

旧持仓自动归入对应分类，原资金账户通过可审计的分类迁移调整保留原可用余额，持仓市值不重复计入净资产。迁移采用确定性标识，双端迁移相同数据不会重复生成调整。开关与初始金额随个人数据同步。数据格式升级到 schemaVersion 8，兼容读取 1–7。

代码联想使用本地公开品种名称目录，首次加载后缓存，支持 2–6 位代码前缀；未收录的新代码保留后台查询。目录不含用户持仓信息，名称匹配与联网行情刷新分开。收益额及收益率统一使用正红、负绿、零灰。贵金属成交总金额与额外手续费分开录入，并实时预览登记后的克重和均价。交易记录支持追加修正并重放成本，原始记录保留，不重复计入克重。

### 行情自动更新频次

与鸿蒙 AutoQuoteRules / AutoQuoteService 保持一致：前台每分钟检查一次；贵金属每分钟；股票按北京时间工作日 09:30–11:30、13:00–15:00 每十五分钟；基金每天成功更新一次。股票窗口不额外内置节假日。退出登录、离线或页面隐藏时暂停，回到前台立即检查；请求中的旧轮次失去写入授权，恢复后接续待处理的查询。各品种成功时间按数据仓库分别保存在本设备，仅成功返回的品种更新时间；失败保留原报价并在下一轮重试。实际完成时间受网络及后台排队影响，不承诺精确到秒。

### 财务导航整合

### 投资内容跨端同步修复

保留原有完整工作台手动同步方式，仅对投资内容补充自动合并上传/拉取：持仓、投资交易、行情、投资类账户及其相关资金记录。保存后约一秒上传，进入/返回前台及前台每三十秒拉取。构建云端文件时，其他内容严格使用云端原值，不上传其他本地个人资料、阅读、预算或任务修改；回写本机时保留这些本地内容和其原手动同步基线。失败保留本地数据并重试。

### 账户页三卡片

账户页顶部以三张等宽方形卡片展示净资产与资产/负债比例、现金/储蓄/投资/其他的资产分布、年度存款目标。桌面并排，窄屏纵向排列。年度目标当前值改为净资产，进度限制在 0–100%，负净资产金额如实显示；已归档目标保留原记录的冻结金额。

负债状态仅按负债/总资产进行界面分档：0 为无负债，低于30%较低，30%至50%适中，50%起偏高，负债超过资产显示资不抵债；该分档不包含收入、利息与还款额。环形分布仅统计参与总览且正余额的四类资产账户，负债不计入分布。

账户页三张卡片调整为等宽等高的紧凑矩形；账户分布图例采用同一行的颜色、分类名称及金额。“已达成（净资产）”显示标签简化为“已达成”，年度目标标题及净资产计算口径保持不变。

资产分布采用浅灰紫分区样式，分类名称与金额紧邻同行；年度目标移除加号，设置/编辑与归档集中到右上同一行，历史归档入口单独保留。

投资收益日历：账户管理左右等宽，右侧日历提供日/周/月/年与收益额/收益率分段切换。私有仓库每日北京时间22点通过GitHub Actions读取同步持仓并刷新行情，独立保存 data/investment-calendar.json，网页自动拉取并缓存；任务可能排队延迟。首次快照作为基线，非连续日期不补造收益，缺失日留空。收益按累计持仓浮盈加已实现收益的日变化计算，剔除新增本金；收益率分母使用上次市值加新增投入，周期收益率按已记录日收益率复合计算。只有已同步到私有仓库的持仓进入后台统计。
