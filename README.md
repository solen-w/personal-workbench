# 我的工作台

访问：https://solen-w.github.io/personal-workbench/

固定授权账号入口为前端校验，不能替代服务端认证；私有内容通过用户的 GitHub 令牌授权访问。原始账号 TXT 不进入本仓库。

## 内容页

- 个人系统：基础情况（可导出 CSV）、学工经历（可导出 CSV）、财务管理。
- 生活系统：身体跟踪、习惯养成、图书管理。
- 目标系统：运动挑战、专项攻克、理论学习。
- 文件系统：工作要求、政策法规、素材收集（文字、图片、文件）。

财务管理按指定顺序包含账户管理、固定预算、结余回收、投资观察、克制分析、存款目标、表盘总览分析。预算以周一至周日为一周；固定预算持续生效，后续可从另一周调整。

可用结余 = 周固定预算 − 实际支出 − 手动回收金额。支出率 = 实际支出 ÷ 周固定预算，以百分比显示，不设主观克制等级；没有预算时不计算支出率。回收须手动记录，不能超过当周可回收结余。可选账户转存仅是账簿记录，转存不重复计作支出。账户余额按期初余额和关联记录计算。

投资价格及数量由用户手动填写，仅计算观察估值；存款目标的已存金额独立手动维护。身体跟踪记录体重、身高、腰围、睡眠与运动，不自动作健康判断。

分组和条目保持用户指定顺序。顶部圆形头像与名称可编辑，保存在当前浏览器；底部保留同步与设置。手机采用抽屉侧栏，平板和电脑使用固定侧栏。

## 数据

内容保存在浏览器 IndexedDB。手动同步的数据文件仍为私有仓库 `data/tasks.json`，格式升级为 schemaVersion 4，包含旧 tasks、删除标记、新 records 及对应删除标记。

旧版模块按名称映射到新分类，文字与图片合并至素材收集的对应子页，保留内容、附件和删除标记。旧任务不会删除，在对应条目的“原有任务”入口可导出。旧版客户端不识别 schemaVersion 4，会拒绝覆盖新版数据；各设备应使用此网址的新版页面。

附件保存在 IndexedDB 和私有仓库 `data/assets/<id>`，不会上传公开网页仓库。单个附件上限 8 MB；主数据 JSON 上限 8 MB。同步先上传附件，再提交引用记录。浏览器中的同步令牌只在当前页面内存存在，刷新后重新输入。

附件按需下载到设备本地，只有已缓存的文件可以离线打开。删除条目会同步删除标记，附件保留以避免破坏其他版本或备份。

导出完整 JSON 备份包含内容和附件，附件未缓存时需要令牌联网下载。附件总量最多 44 MB，导入文件最大 64 MB；更大资料应保留 GitHub 私有仓库副本并分别下载附件。

## 验证

`npm test`：29 项测试覆盖旧数据迁移、金额、进度、深层字段比较、内容冲突、习惯打卡合并和附件路径校验。

独立 DOM / IndexedDB 模拟环境验证了十二类内容与七个财务子页的创建、编辑、打卡、周预算、回收和支出率展示、CSV 导出、素材子页、搜索、自定义名称、备份导入导出、删除冲突与退出登录。GitHub 读写和附件上传在该测试中使用模拟接口；不代表真实账号同步或鸿蒙真机验证。

## 微信读书

图书管理包含微信读书阅读看板和原有个人书目。看板展示累计与年度阅读/收听时长、每日热力表、按封面展示的电子书和有声书；支持搜索和状态筛选。书架里未读的书不会默认当作已读书籍。接口未返回的日期显示为未知，不填零。

官方 Skill 1.0.6 使用 `https://i.weread.qq.com/api/agent/gateway`。跨域检测仅允许微信读书源站，因此公开静态网页不收集或直传微信读书密钥。私有数据仓库中的手动 GitHub Actions 工作流读取 Secret `WEREAD_API_KEY`，将净化后的阅读快照写入 `data/weread.json`；网页用已有 GitHub Contents 令牌读取该文件并缓存到当前设备。密钥不写入快照、源码、日志或本地页面。该工作流没有定时任务。

首次使用：在图书管理的“连接配置”中打开私有仓库 Secrets，新建 `WEREAD_API_KEY`；再运行“微信读书同步”工作流。成功后在网页点击“读取阅读数据”。历史年份可在运行工作流时填入 year，多次运行会保留已获取年份。年度明细缺失时，同步程序按自然月读取每日明细；累计时长始终使用 overall 的 totalReadTime，年度时长使用对应年的 totalReadTime，单位均为秒。网页缓存快照后可离线查看数据；外部封面是否可离线显示取决于浏览器图片缓存。

官方文档：https://github.com/Tencent/WeChatReading/tree/main/skills

新增验证：4 项阅读数据/热力表测试，私有同步程序 3 项模拟接口测试；DOM 模拟验证读取、缓存、书籍画板搜索与配置入口。未使用用户真实 API Key，尚未完成真实账号端到端验证。

微信读书画板支持“修改书名”和“恢复原书名”。自定义名称按书籍编号保存为私有内容记录，使用现有手动同步及备份机制；再次读取微信读书快照会保留名称。修改影响工作台显示，源站书名保持其接口返回值；搜索支持原名和自定义名。数据格式升级为 schemaVersion 4，旧页面会拒绝覆盖新版数据。
