# 我的工作台

访问：https://solen-w.github.io/personal-workbench/

## 登录

使用用户指定的十六进制账号转换得到的十进制账号登录。固定账号在 `config.js`，原始 TXT 不包含在本仓库。

当前登录为静态网页的前端入口校验，源码公开，不能替代服务端身份认证。私有数据仓库仍通过 GitHub 访问令牌授权。

登录会话保存在当前标签页的 sessionStorage；退出时清除会话与页面内存中的同步令牌。任务不会因退出而删除。

## 导航与外观

左侧分为顶部外观、中部分组导航、底部同步与设置三部分。五个分组和十个条目严格保留用户指定文字与顺序。

点击顶部圆形头像或名称可编辑外观，图片裁切为正方形并缩小后在圆框显示。头像和名称保存在当前浏览器本地，不上传公开仓库。

每个条目提供独立的任务列表。旧版无分类任务归入第一个条目。任务分类随任务数据一起同步。

电脑和平板使用固定侧栏，手机使用可关闭的抽屉导航。保留简洁界面，不增加装饰性小字。

## 数据与同步

任务保存在浏览器 IndexedDB，通过用户配置的 GitHub 私有仓库手动同步。令牌仅在当前页面内存使用，刷新后重新输入。

首次在线打开并完成缓存后支持离线使用。支持 JSON 备份导入导出。GitHub Pages 从 main 分支根目录发布。

## 验证

运行 `npm test`。账号校验、导航顺序、分类兼容及核心合并共 12 项测试通过。手机和平板仍需要真机验证。
