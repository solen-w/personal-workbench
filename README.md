# 我的工作台

访问：https://solen-w.github.io/personal-workbench/

固定授权账号入口为前端校验，不能替代服务端认证；私有内容通过用户的 GitHub 令牌授权访问。原始账号 TXT 不进入本仓库。

## 内容页

- 命宫本元：个人资料，姓名、联系方式、职业、简介。
- 履迹平生：学习与工作经历，机构、专业或职位、起止时间及收获。
- 财帛大有：收入支出记录、账户、分类、月份筛选及结余统计。金额按分计算。
- 乾元矢志：专项目标、数值进度、期限、状态和行动计划。
- 恒久不已：习惯、每周目标天数、按日打卡及周视图。
- 文曲含章：文字素材、标签、来源、正文及复制。
- 万象包罗：图片附件、标签、来源、查看与下载。
- 继明开卷：书籍、阅读状态、页数进度、起止日期及阅读笔记。
- 申命行事：工作文件、分类、日期、链接及附件下载。
- 节以制度：政策文件、文号、发布机构、施行日期、效力状态、原文及附件。

分组和条目保持用户指定顺序。顶部圆形头像与名称可编辑，保存在当前浏览器；底部保留同步与设置。手机采用抽屉侧栏，平板和电脑使用固定侧栏。

## 数据

内容保存在浏览器 IndexedDB。手动同步的数据文件仍为私有仓库 `data/tasks.json`，格式升级为 schemaVersion 2，包含旧 tasks、删除标记、新 records 及对应删除标记。

旧任务不会删除，在对应条目的“原有任务”入口可导出。旧版客户端不识别 schemaVersion 2，会拒绝覆盖新版数据；各设备应使用此网址的新版页面。

附件保存在 IndexedDB 和私有仓库 `data/assets/<id>`，不会上传公开网页仓库。单个附件上限 8 MB；主数据 JSON 上限 8 MB。同步先上传附件，再提交引用记录。浏览器中的同步令牌只在当前页面内存存在，刷新后重新输入。

附件按需下载到设备本地，只有已缓存的文件可以离线打开。删除条目会同步删除标记，附件保留以避免破坏其他版本或备份。

导出完整 JSON 备份包含内容和附件，附件未缓存时需要令牌联网下载。附件总量最多 44 MB，导入文件最大 64 MB；更大资料应保留 GitHub 私有仓库副本并分别下载附件。

## 验证

`npm test`：21 项测试覆盖旧数据迁移、金额、进度、深层字段比较、内容冲突、习惯打卡合并和附件路径校验。

独立 DOM / IndexedDB 模拟环境验证了十类内容的创建、编辑、打卡、搜索、自定义名称、备份导入导出、删除冲突与退出登录。GitHub 读写和附件上传在该测试中使用模拟接口；不代表真实账号同步或鸿蒙真机验证。
